# PetMate 进化路线图 (v1.2 → v2.0)

## 当前状态 (v1.2.0)

**已完成**:
- MVP核心功能（91天行动卡、风险判断、AI问答）
- 用户系统（登录/注册/游客）
- 支付系统（模拟+微信预留）
- 笔记+推送提醒
- 部署上线（Vercel）
- 数据持久化（Supabase预留）
- PWA支持

**待激活**:
- Supabase数据库（Schema已准备，未连接）
- 微信支付（模块已就绪，未配置商户号）

---

## 进化阶段规划

### Phase 5: 数据层激活 (v1.3.0)

**目标**: 真实数据持久化，告别内存存储

**任务**:
1. 创建Supabase项目并执行Schema
2. 修改API路由，优先使用数据库，内存作fallback
3. 用户数据持久化测试
4. 迁移现有测试用户数据

**收益**: 用户数据不丢失，支持多设备同步

---

### Phase 6: 内容层扩展 (v1.4.0)

**目标**: 个性化内容适配

**任务**:
1. 猫咪品种适配模块
   - 不同品种的特殊注意事项
   - 幼猫/成年猫/老年猫差异化建议
2. 用户画像扩展
   - 养猫经验等级
   - 家庭环境（独居/有小孩/多宠物）
3. 行动卡个性化引擎
   - 根据用户画像调整行动顺序和内容
4. 多语言预留（英文版准备）

**收益**: 内容更精准，用户体验提升

---

### Phase 7: 商业层完善 (v1.5.0)

**目标**: 真实支付接入，订阅模式

**任务**:
1. 微信支付沙箱测试
2. 支付回调处理
3. 订单状态同步
4. 订阅模式设计
   - 基础版（免费）: Day 0-3
   - 完整版（¥29）: Day 0-90
   - 专家版（¥99）: 完整版 + 1对1咨询
5. 退款流程预留

**收益**: 真实收入能力

---

### Phase 8: AI层升级 (v1.6.0)

**目标**: 更智能的问答和推荐

**任务**:
1. RAG增强问答
   - 行动卡知识库检索
   - 常见问题FAQ库
2. 上下文记忆
   - 用户历史问题记录
   - 个人情况记忆
3. 主动提醒优化
   - 根据用户进度智能提醒
   - 异常情况主动预警
4. AI生成个性化建议
   - 基于用户笔记生成总结
   - 行动完成度分析

**收益**: AI更像"私人养猫顾问"

---

### Phase 9: 社区层建设 (v1.7.0)

**目标**: 用户互动和分享

**任务**:
1. 用户分享功能
   - 笔记分享到小红书/朋友圈
   - 养猫日记导出PDF
2. 成就系统
   - 完成里程碑徽章
   - 养猫达人等级
3. 社区问答（可选）
   - 用户互助问答
   - 专家入驻预留
4.UGC内容
   - 用户投稿行动建议
   - 优质内容收录

**收益**: 用户粘性增强，自发传播

---

### Phase 10: 运营层完善 (v1.8.0)

**目标**: 数据驱动增长

**任务**:
1. 数据埋点
   - 用户行为追踪
   - 转化漏斗分析
2. SEO优化
   - 搜索引擎收录
   - 关键词优化
3. A/B测试框架
   - Landing Page多版本
   - 价格策略测试
4. 运营后台
   - 用户管理
   - 内容管理
   - 数据看板

**收益**: 可量化增长

---

### Phase 11: 产品层打磨 (v1.9.0)

**目标**: 用户体验极致化

**任务**:
1. UI/UX优化
   - 设计规范统一
   - 动效和交互优化
2. 性能优化
   - 图片CDN
   - 缓存策略优化
3. 错误处理完善
   - 网络异常提示
   - 数据同步冲突处理
4. 无障碍支持
   - 视障用户适配
   - 老年用户友好

**收益**: 产品质量达到上线标准

---

### Phase 12: v2.0发布 (v2.0.0)

**目标**: 正式版发布

**任务**:
1. 全面测试
2. 用户验收测试
3. 市场推广准备
4. 正式发布

## 优先级排序

基于当前资源，建议执行顺序：

| 优先级 | Phase | 理由 |
|--------|-------|------|
| P0 | Phase 5 | 数据持久化是基础设施，先激活 |
| P1 | Phase 7 | 真实支付接入，建立收入能力 |
| P1 | Phase 6 | 内容差异化是核心竞争力 |
| P2 | Phase 8 | AI升级提升用户价值感知 |
| P2 | Phase 9 | 社区功能增加粘性和传播 |
| P3 | Phase 10-11 | 运营和打磨，规模化准备 |
