### 当前技术栈

```
Frontend:  Next.js 16 App Router + TypeScript + Tailwind CSS 4
Backend:   Next.js API Routes
AI:        腾讯混元 (hunyuan-turbos)
Data:      localStorage (fallback) + Supabase (未激活)
Deploy:    Vercel (海外) + GitHub
```

### 核心问题识别

| 问题类型 | 具体问题 | 影响 | 优先级 |
|----------|----------|------|--------|
| **数据安全** | 数据仅存localStorage，清除即丢失 | 用户流失风险高 | P0 |
| **认证缺失** | 无真实用户认证，游客模式不可持续 | 无法建立用户体系 | P0 |
| **测试缺失** | 无自动化测试，回归风险高 | 质量不可控 | P1 |
| **性能未优化** | 未做代码分割、图片优化 | 移动端体验差 | P1 |
| **AI体验一般** | 问答较泛，缺少上下文记忆 | 用户价值感不足 | P1 |
| **UI粗糙** | 设计不够精致，缺少动效 | 转化率受限 | P2 |
| **内容单薄** | 品种个性化不够深入 | 差异化不足 | P2 |
